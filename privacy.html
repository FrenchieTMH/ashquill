ASHQUILL Commands Privacy Terms

Privacy Policy

Last updated: November 9, 2026

Ashquill is a free, fan-made Discord bot for Elder Scrolls lore, quotes and trivia. It is run as a hobby project by one person (GitHub: FrenchieTMH). This page explains what Ashquill can see, what it stores, and how to have your data removed.

What Ashquill can see

Ashquill uses Discord’s Message Content permission so it can recognise commands (such as !trivia) and check answers while a game round is running. It does not save your messages, apart from the submissions and reports described below.

What Ashquill stores

  • Leaderboards: your Discord user ID and your points, per server and per game.
  • Submissions and reports: if you use the submit or report commands, Ashquill keeps what you wrote (a trivia question, a quote, or a report link and reason), your Discord user ID, and the ID of the server. If a submission is approved, it is added to Ashquill’s question lists, and that line can carry the ID of the person who submitted it.
  • Server settings: a server’s command prefix and, if an admin turns it on, the new-member welcome settings (channel and message text).
  • Logs: a daily log file on the owner’s computer records bot activity: which command was used, by which Discord username and user ID, in which server, plus submission and report text, review decisions and errors. Log files are deleted automatically after 30 days.

New-member welcome (optional)

Off by default. If a server admin switches it on, Ashquill receives join events for that server and greets each newcomer in a channel the admin chose. Nothing about the new member is stored.

Direct messages

Ashquill may send you a direct message to tell you the outcome of a submission or report you made.

Who else receives data

  • I do not sell, rent or share your data, and Ashquill has no ads, analytics or AI training.
  • The lore command fetches pages from the Unofficial Elder Scrolls Pages (uesp.net). A topic you search for may be sent to that site; your Discord identity is not.
  • Discord processes messages under its own Privacy Policy. Ashquill currently runs on the owner’s personal computer.

Keeping and deleting data

Scores and submission records are kept until they are removed. To have your data deleted, or a server’s data deleted after Ashquill is removed from it, open an issue with your Discord user ID (or the server ID). I will delete your leaderboard entries and submission records, and remove your ID from any approved questions.

Age

Discord’s own minimum-age rules apply. Ashquill is not directed at children.

Changes

If this policy changes, the date at the top will change with it.
